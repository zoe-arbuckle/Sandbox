```
You are an expert C# mentor.

I am a software engineer with experience in [background].

Teach me [topic].

For each lesson:
1. Explain the concept
2. Show a simple example
3. Show a production-quality example
4. Describe common mistakes
5. Give me an exercise
6. Review my solution after I complete it
```

#### Personalized Teaching
Ask AI to create a learning path tailored to your experience level.

Examples:

> I'm a Staff Software Engineer with experience in Java. Create a 6-week plan to learn modern C# and .NET.

> Teach me [topic] in C# assuming I am already familiar with [background].

> Explain [topic] from first principles and compare it to [equivalent topic from background].

#### Practical Exercises
Ask AI to generate a practical exercise.

Examples:
> Give me three progressively harder [topic] exercises.

> Create a real-world [topic] challenge using customer and order data.
 
> Review my solution and suggest improvements.

#### Code Reviews
Paste code and ask:
> Review this code like a senior C# architect

> What C# language features am I not using effectively?

> How would this look using modern C#/.NET 10 patterns?

You can also ask for:
- performance improvements
- readability improvements
- best C# practices
- threading issues

#### Create Quizzes
After studying a topic: 
> Quiz me on [topic]

> Give me interview questions about [topic]
Ask AI not to reveal answers immediately

#### Incremental Challenges
> Act as a C# mentor. Give me a problem slightly above my current level. Review my answer and then give me the next challenge.

#### Interview Style Deep Dive
> Keep asking harder questions about [topic] until I get one wrong

> Pretend you're interviewing me for a Senior .NET Engineer role. 

Based on these interview style deep dives, AI can suggest topics to study based on weak and strong points.
